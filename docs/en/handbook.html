§1. Overview

This page is the single reference for day-to-day OpenCode skills management. Treat it as the always-open cheat sheet: domain taxonomy, problem-solving workflows, the Skills Graph, and real graph evolution.

What's on this page

  • The decision rules and keywords for all 6 skill domains
  • The problem-solving workflow from idea to launch, growth, iteration, and retrospective learning
  • A condensed reference for all 11 slash commands
  • A live render of the current Skills Graph + a legend
  • Real and hypothetical graph evolution cases (State 0 → State N)

What's not on this page

  • Install steps — see Getting Started
  • Two-layer architecture deep dive — see Architecture

Who it's for

  • Users who already have ≥ 3 skills installed and need "which one to load / which one to invoke" decisions in seconds
  • Developers who want to understand why the graph looks the way it does and how it changes when a new skill is installed
  • Read-only contexts where you can't run commands (airplane, client laptop, pure web)

§2. Domain Taxonomy

Six domains. One rule: when the classifier is uncertain, ask the user. The classifier never silently miscategorizes.

How inference works

  1. Concatenate name + description, lowercase
  2. For each domain, count how many of its keywords appear (each keyword counted at most once)
  3. Pick the highest-scoring domain. Ties broken by priority order:
ip → desktop → founder → meta → closeout → tooling
  1. If every score is 0 → returns uncategorized; the agent prompts the user to manually pick
